# ООО «У кофейня» — 3D-печать на заказ, Минск

Статический сайт: index.html, politika.html, assets. Собран build.py.

## Перед запуском
1. Вписать телефон и мессенджер: сейчас в брифе их нет, поэтому заявка собирается в текст с кнопкой «Скопировать». Когда пришлёте номер, в build.py есть PHONE и PHONE_H, плюс нужно вернуть кнопки «Позвонить» и WhatsApp в шапку и в блок контактов.
2. УНП в подвал и в политику.
3. Реальные фото изделий вместо сгенерированных (assets/img).
4. Подтвердить адрес: Мира пр., 1, Минск.
